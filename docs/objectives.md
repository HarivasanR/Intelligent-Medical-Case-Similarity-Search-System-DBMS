# Objectives

1. Model normalized relational medical-case information in MySQL.
2. Store variable laboratory, examination, and report structures in MongoDB without duplicating the relational model.
3. Represent clinically relevant case text as vectors and retrieve neighbours from Qdrant using cosine similarity.
4. Demonstrate authentication, two roles, validation, constraints, DDL, DML, advanced DBMS features, and a functional Next.js interface.
5. Keep the system simple enough to explain and operate during a two-student viva.
