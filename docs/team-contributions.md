# Team contribution plan

For a two-member submission, use Git history to show individual contributions. A clear split is:

- **Member 1 - Database and services:** MySQL schema/queries/routines, MongoDB model, Qdrant indexing, seed scripts, and API integration.
- **Member 2 - Application and quality:** Next.js UI, authentication/authorization, forms, validation, search experience, tests, and documentation/screenshots.

Both members should review the other's work and make meaningful commits in GitHub.
